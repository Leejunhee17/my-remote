# 점검 결과(공유용)

GPU 서버의 점검 스크립트 `check.sh` 가 만든 **공유용** 보고서(`check_공유용_*.txt`)만 여기에 올려요.
공유용은 서버 이름·IP·NAS 주소·계정·폴더 이름을 가린 사본이에요. 원본(`*_report_*.txt`)은 올리지 않아요.
2026-11-06 서버 1(`p1`) 보고서는 `/app/tmp` 폴더 이름을 가리면서 `tmp` 를 모두 `서버폴더1` 로 바꿨어요(`/서버폴더1` 은 `/tmp`, `/data/서버폴더1` 은 `/data/tmp`). 다음 점검부터는 `tmp` 같은 흔한 이름은 가리지 않아요.
가져오는 방법은 `docs/4_네트워크.md` 의 "결과 가져오기" 에 있어요.

접근 PC(인터넷이 되는 PC) 점검(`pc\check.ps1`)의 `pc_check_공유용_*.txt` 와 WildScenes 링크 점검(`pc\wildscenes_check.ps1`)의 `wildscenes_check_공유용_*.txt` 도 여기에 올라와요. 스크립트가 계정·PC 이름, 프록시 주소, 사내 IP, 토큰·키·서명을 가린 뒤, 올려도 되는지 물어보고 올려요.
