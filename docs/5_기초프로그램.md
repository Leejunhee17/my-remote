# 기초 프로그램

서버 화면(컨테이너 밖)에서 쓰는 명령 모음이에요. 인터넷이 없는 서버에서도 tmux로 학습 화면을 띄워 두고, nvtop으로 GPU를 보고, rsync로 파일을 옮길 수 있어요.
처음 설치는 `docs/1_처음_설치.md` 의 1·2단계(접근 PC `pc\pack_build.ps1` → B200 서버 `server/admin_setup.sh`, `server/pack_install.sh`)를 따르세요.

## 들어 있는 것

목록은 `lists/tools.txt` 에 있고, conda-forge 에서 받아 B200 서버의 `/app/shared/tools` 에 설치해요. 목록에 적힌 것은 57개예요(함께 딸려 오는 패키지는 따로 세지 않았어요).

| 용도 | 명령 |
|---|---|
| 화면 유지·편집 | `tmux`, `screen`, `vim`, `nvim`, `nano`, `micro`, `less` |
| GPU·시스템 보기 | `nvtop`, `htop`, `btop`, `ncdu`, `dust`, `duf`, `lsof`, `strace`, `gdb` |
| 파일 찾기·옮기기 | `rsync`, `tree`, `rg`(ripgrep), `fd`, `fzf`, `bat`, `eza`, `zoxide`, `jq`, `yq`, `dos2unix` |
| 압축 | `zip`, `unzip`, `7za`, `pigz`, `zstd` |
| git | `git`, `git-lfs`, `delta`, `lazygit` |
| 빌드 | `make`, `cmake`, `ninja`, `pkg-config`, `gcc`, `g++`, `ccache`, `patchelf`, `clang-format`, `shellcheck` |
| 기타 | `python`(3.12), `uv`, `ffmpeg`, `magick`(ImageMagick), `sqlite3`, `bc`, `parallel`, `just`, `hyperfine`, `entr`, `direnv` |

- 공용 계정으로 접속하면 기초 프로그램 폴더가 PATH 맨 뒤에 붙어요. 서버에 같은 명령이 있으면 서버에 원래 있던 것이 먼저 실행돼요.
- 버전은 접근 PC에서 `pc\pack_build.ps1` 을 실행한 날 기준으로 정해져요. B200 서버의 `/app/shared/pack_info.txt` 에서 확인하세요.
- glibc 2.35 이상에 맞춰 만든 것이라 B200 서버의 Ubuntu 24.04(glibc 2.39)에서 그대로 쓸 수 있어요.

## Python 패키지는 공용으로 두지 않아요

팀원은 필요한 Python 패키지를 도커 이미지에 넣어 와요. 공용 휠은 Python 버전(3.12)이 이미지와 맞아야 하고 이미지에 든 torch와 충돌할 수 있어서 두지 않아요.
이미지에 없는 패키지를 급히 추가해야 하면, 팀원이 자기 PC에서 받아 작업 폴더에 올려 설치해요. 방법은 `team/사용_안내.md` 의 "5. 컨테이너에서 실행하고 고치기" 에 있는 "패키지를 더 설치할 때" 를 보세요.

예전 버전의 스크립트가 만든 `/app/shared/wheels`, `/app/shared/venv` 가 남아 있으면 `pack_install.sh` 가 `[주의]` 로 알려 줘요. 쓰는 사람이 없으면 root 로 지우세요.

## 목록 바꾸기

1. 접근 PC에서 `lists/tools.txt` 를 고치세요. conda-forge 의 패키지 이름을 띄어 써서 적어요.
2. `docs/1_처음_설치.md` 의 1단계 중 묶음 만들기(`pack_build.ps1`)를 다시 하고, 새 `b200-pack.tar` 를 `/app/upload` 에 올린 뒤 root 로 `/app/shared/bin/b200 fetch b200-pack.tar` 를 실행해 지문을 확인하세요.
3. 아래 "다시 설치하기" 로 서버에 설치하세요. `pack_install.sh` 는 목록이 바뀐 것을 알아채도 지금 설치된 것을 그대로 두고 `[주의]` 로만 알려 줘요.
4. 엑셀의 '기초 프로그램' 시트에 바뀐 내용을 적으세요.

## 다시 설치하기

B200 서버의 기초 프로그램 폴더를 통째로 새로 만들어요. 그동안 기초 프로그램을 쓸 수 없으니 팀원이 쓰지 않을 때 하세요.

```bash
# [B200 서버] root
cd /app/inbox && tar xf b200-pack.tar && bash admin_setup.sh && B200_REBUILD_TOOLS=1 bash pack_install.sh /app/shared   # admin_setup.sh 는 묶음 안의 고친 도우미를 다시 설치해요
```

끝나면 완료 상자에 "모두 정상" 이 나와요.

## 하나만 지우기

예를 들어 잘못 설치한 `neovim` 을 지우려면 이렇게 해요.

```bash
# [B200 서버] root
MAMBA_ROOT_PREFIX=/app/shared/mamba /app/shared/tools/bin/micromamba remove -p /app/shared/tools --offline -y neovim
```
