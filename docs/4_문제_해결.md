# 문제 해결과 서버 관리

반입 스크립트를 쓰다가 막혔을 때 할 일과, B200 서버의 공용 폴더를 관리하는 방법이에요.

## 기록 파일 위치

해결이 안 되면 아래 기록 파일을 담당자에게 보내 주세요.

| 어디서 | 기록 파일 |
|---|---|
| 접근 PC | `D:\b200\pack\build.log`, `D:\b200\datasets\download.log`, `D:\b200\models\download.log` |
| B200 서버 | `~/shared/logs/` 에서 가장 최근 파일 |

## 자주 나는 문제

| 어디서 | 메시지 | 할 일 |
|---|---|---|
| 접근 PC | `스크립트를 실행할 수 없습니다` | `-ExecutionPolicy Bypass` 가 빠졌어요. README의 명령을 그대로 복사해 실행하세요 |
| 접근 PC | `파일을 찾을 수 없습니다` (`.\pack_build.ps1` 등) | 스크립트가 `pc\` 폴더로 옮겨졌어요. `.\pc\pack_build.ps1` 처럼 실행하세요 |
| 접근 PC | `uv 가 없다`, `micromamba 가 없다` | 설치한 뒤 PowerShell 창을 새로 여세요. 그래도 안 되면 `uv.exe`, `micromamba.exe` 를 `D:\b200` 에 넣으세요. micromamba 위치는 PowerShell에서 `$env:MAMBA_EXE` 로 확인할 수 있어요 |
| 접근 PC | `인터넷: … 에 접속 안 됨` | 스크립트가 회사망 문제(인증서 폐기 확인, 윈도우 프록시)는 스스로 우회해요. 그래도 안 되면 사내 IT에 프록시 주소를 물어 실행 전에 `$env:HTTPS_PROXY = "http://프록시주소:포트"` 를 입력하세요 |
| 접근 PC | `micromamba 가 conda-forge 목록을 받지 못했다` | 화면의 `[문제]` 아래 줄과 경고를 담당자에게 보내 주세요 |
| 접근 PC | `WildScenes2d 폴더를 찾지 못했다`, `접속 정보가 만료됐거나 막혔다` | WildScenes 접속 정보는 약 48시간만 유효해요. 포털에서 새로 받아 같은 명령을 다시 실행하세요 |
| 접근 PC | `Google Drive 접속 안 됨` | 지금 접근 PC에서는 막혀 있어요. RELLIS-3D, TAS500, GO만 건너뛰고 나머지는 받아요 |
| B200 서버 | `올리는 중에 파일이 깨졌다` | 화면에 나온 파일만 접근 PC에서 다시 올리세요. 1단계라면 묶음 파일을 다시 올리세요 |
| B200 서버 | `남은 공간이 … GB 다` | 다 푼 `b200-pack.tar` 를 지우세요. 홈(10 GB)에 설치하려 했다면 `bash pack_install.sh /app/shared` 처럼 `/app` 경로를 붙이세요 |
| B200 서버 | `glibc 가 … 안 맞는다` | 화면에 나온 `-Glibc` 값을 붙여 접근 PC에서 1단계를 다시 실행하고, 새 묶음 파일을 올리세요 |
| B200 서버 | `기초 프로그램에 없는 명령: …` | `lists/tools.txt` 의 패키지 이름이 실제 명령과 다른 경우예요. 해당 명령을 담당자에게 알려 주세요 |
| B200 서버 | `라벨을 못 찾음` | 화면의 "지금 구조" 를 보고 `docs/2_데이터셋.md` 의 "학습 코드가 읽는 라벨 위치" 대로 폴더를 옮기세요 |

## 설치 스크립트만 고쳐서 다시 올리기

`server/` 의 스크립트를 고쳤다면 그 파일 하나만 B200 서버의 같은 자리에 덮어써도 돼요. 설치 스크립트는 체크섬 검사에서 빠져 있어서 "깨졌다" 오류가 나지 않아요.

## 기초 프로그램 다시 설치하기

`lists/tools.txt` 를 바꿨다면 1단계를 다시 하세요. 접근 PC에서는 이미 받은 파일을 건너뛰어 금방 끝나요.
B200 서버에서는 기초 프로그램 폴더를 통째로 새로 만들어요. 그동안 기초 프로그램을 쓸 수 없으니 팀원이 쓰지 않을 때 하세요.

```bash
# [B200 서버] 터미널
cd /app/inbox && tar xf b200-pack.tar && B200_REBUILD_TOOLS=1 bash pack_install.sh
```

기초 프로그램 하나만 지우려면 이렇게 해요(예: 잘못 설치한 `neovim`).

```bash
# [B200 서버] 터미널
MAMBA_ROOT_PREFIX=~/shared/mamba ~/shared/tools/bin/micromamba remove -p ~/shared/tools --offline -y neovim
```

## 공용 폴더를 큰 디스크로 옮기기

홈(10 GB)에 이미 설치한 `~/shared` 를 `/app` 으로 옮길 때 써요. 복사한 뒤 파일 수와 크기를 비교하고, 홈에는 같은 이름의 링크를 남겨서 경로와 설치된 환경을 그대로 쓸 수 있어요.
`server/move_shared.sh` 는 1단계 묶음 파일 안에 들어 있어요.

```bash
# [B200 서버] 터미널
bash /app/inbox/move_shared.sh /app
```

## 개인 작업 폴더 만들기

홈이 10 GB라 개인 작업 폴더도 `/app` 에 두고, 홈에는 링크만 둬요. 처음 한 번만 하면 돼요.

```bash
# [B200 서버] 터미널
mkdir -p /app/workspace && ln -s /app/workspace ~/workspace
```
