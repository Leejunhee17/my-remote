# 사전학습 모델 받기와 쓰기

야지(오프로드) 주행의 세그멘테이션, 주행 가능 영역, 깊이 추정, VLM 연구와 주행 영상 의사 라벨(pseudo-label) 만들기에 쓸 Hugging Face 사전학습 모델을 GPU 서버에 준비하는 방법이에요.
처음 설치는 `docs/1_처음_설치.md` 의 5단계(접근 PC `pc\models_download.ps1` → GPU 서버 `server/models_install.sh`)를 따르세요.
받은 모델은 GPU 서버의 `/app/shared/models/<만든 곳>/<모델>` 에 설치돼서 인터넷 없이 경로로 불러 쓸 수 있어요.

## 받고 설치하기

```powershell
# [접근 PC] PowerShell
cd D:\b200
powershell -ExecutionPolicy Bypass -File .\pc\models_download.ps1
```

`D:\b200\models` 폴더를 통째로 공용 계정의 FileZilla로 GPU 서버의 `/app/upload` 에 올리세요. root 로 새로 복사해 지문을 확인한 뒤 설치하세요(지문은 접근 PC 스크립트 끝에 나와요).

```bash
# [GPU 서버] root
/app/shared/bin/b200 fetch models                  # 새로 복사하고 지문을 보여 줘요. 접근 PC 화면의 지문과 같은지
bash /app/inbox/models/models_install.sh
```

- `-Only seg,enc,backbone` 처럼 그룹을 골라 나눠 받을 수 있어요.
- 승인이 필요한 모델(DINOv3, SAM 3, SAM 3.1, Cosmos-Reason2)은 Hugging Face 토큰이 있어야 해요. 아래 "승인이 필요한 모델(gated) 받기" 를 보세요.
- 끝나면 모델마다 크기와 라이선스를 보여 줘요.

## 받는 모델

목록은 `lists/models.txt` 에 있어요. 그룹마다 기본으로 받는 모델과, 앞에 `#` 이 붙어 있어 기본으로는 받지 않는 선택 모델이 있어요. 크기는 2026-11-02 기준 대략적인 값이에요.

오프로드 장면은 풀, 나무, 흙, 물웅덩이, 바위가 대부분이에요. 그래서 도시 도로(Cityscapes)로 학습한 모델보다 자연물 클래스가 많은 ADE20K, Mapillary로 학습한 모델을 기본으로 골랐어요. Cityscapes 모델은 선택 모델로 남겨 뒀어요.

주행 영상 의사 라벨은 한 번 만들어 오래 쓰니 속도보다 품질이 중요해요. 그래서 H200 한 장(141 GB)에 올라가는 가장 큰 급(DINOv3 7B, DA3 Giant, MoGe-3 ViT-g, Qwen3.8-27B, Cosmos-Reason2-32B)을 기본으로 넣었어요. H200 여러 장이 필요한 수백 GB 급 VLM은 `vlmxl` 그룹에 선택 모델로 따로 뒀어요.

- 같은 가중치가 여러 형식으로 있으면 safetensors 만 받아요. ONNX, TensorFlow, 예시 이미지는 받지 않아요.
- 모델마다 받은 시점의 커밋, 파일 수, 라이선스를 `b200_model.json` 에 남겨요.
- 라이선스가 모델마다 달라요. DINOv3, SAM 3, SAM 3.1, Cosmos-Reason2, Rex-Omni(IDEA), Falcon-Perception(TII)은 자체 라이선스예요. NVIDIA SegFormer, Depth Anything V2 Large, DA3 Giant(`DA3NESTED-GIANT-LARGE-1.1`), Video Depth Anything은 비상업 라이선스예요. MoGe-3는 코드만 MIT이고 가중치 라이선스가 적혀 있지 않아요. 쓰기 전에 모델 페이지에서 확인하세요.
- 비상업 모델로 만든 의사 라벨로 제품에 들어갈 모델을 학습할 거라면, 미리 담당 부서에 확인하세요. 상업적으로 쓸 수 있는 깊이 모델은 DA3METRIC/DA3MONO-LARGE(Apache-2.0)와 선택 모델 `map-anything-apache`, `lingbot-map` 이에요.
- 오프로드 데이터셋으로 학습한 공개 모델은 아직 적어요. 기본으로 받는 것은 GOOSE-M2F 하나예요(ICRA 2026 GOOSE 2D 챌린지 3위, 64클래스). GOOSE·RELLIS-3D로 학습한 mmsegmentation 체크포인트 모음(`roboticslaburjc-org/cross-dataset-visual-offroad-segmentation`)을 선택 모델로 넣어 뒀어요. 용량이 크고 mmsegmentation이 있어야 불러올 수 있어요.

## 의사 라벨 만들기

라벨 없는 주행 영상에 품질 높은 의사 라벨을 만드는 권장 순서예요. 핵심은 **같은 일을 하는 모델을 둘 이상 돌려, 결과가 같은 곳만 라벨로 쓰고 결과가 다른 곳만 사람이 보는 것**이에요.

1. **검출**: 핵심 프레임마다 LLMDet-L, MM-Grounding-DINO-L, Rex-Omni로 박스를 찾고 WBF로 합쳐요. 흙, 풀, 물웅덩이처럼 모양이 정해지지 않은 클래스는 SAM 3.1(또는 SAM 3) 텍스트 프롬프트와 Falcon-Perception으로 바로 마스크를 만들어요.
2. **영상으로 퍼뜨리기**: SAM 3.1로 앞뒤 양방향으로 추적해요. SeC-4B로 한 번 더 추적하고, 두 추적 결과의 IoU가 낮은 구간만 검토 목록에 올려요.
3. **클래스 붙이기와 검수**: 마스크를 잘라 SigLIP2 giant로 클래스 이름과 맞춰 봐요. 표본 프레임은 Qwen3.8-27B, Cosmos-Reason2-32B에게 맞는지 물어보고, 둘이 다르게 답한 것만 사람이 봐요.
4. **교사 모델로 다듬기**: DINOv3 7B(고정) + 어댑터 + Mask2Former를 GOOSE, RELLIS-3D, RUGD와 걸러 낸 의사 라벨로 학습해요(GOOSE 2026 챌린지 1위와 같은 구성). 이 교사 모델로 영상 전체를 다시 라벨링하면서 좌우 반전·여러 크기 추론(TTA)과 앞뒤 프레임 투표로 흔들림을 줄여요. 마지막에 ViT-L이나 C-RADIOv4-H 학생 모델로 증류해요.
5. **기하 라벨**: DA3 Giant로 다중 시점 미터 깊이와 카메라 자세를, MoGe-3로 법선(경사·단차)을, Video Depth Anything으로 프레임 사이가 흔들리지 않는 깊이를 만들어요. DA3METRIC과 크게 다른 곳은 버려요.

- SAM 3.1, MoGe-3, Video Depth Anything, DA3, SeC, Rex-Omni는 transformers 만으로는 못 써요. 접근 PC 스크립트가 GitHub 코드를 `code.zip` 으로 함께 받고 서버 스크립트가 `<모델>/code` 에 풀어 두지만, 의존 패키지는 이미지에 넣어 오세요.
- 영상 추적 점수(J&F)는 물체가 잠깐씩만 보이는 영상에서 빈 마스크를 높게 쳐 줄 때가 있어요. 추적기를 비교할 때는 표본 프레임을 사람이 직접 확인하세요.

## 아주 큰 VLM 받기 (vlmxl)

Qwen3.5-397B-A17B-FP8(406 GB)은 공개된 Qwen VLM 중 가장 크고, 박스·위치 찾기 점수(RefCOCO 92.3)가 가장 높아요. 다만 의사 라벨 검수 점수는 Qwen3.8-27B와 비슷해서, 기본 모델로 먼저 해 보고, 어려운 장면을 판정하기에 부족할 때 받으세요.

1. `lists/models.txt` 의 `vlmxl` 줄 맨 앞 `#` 을 지워요.
2. 접근 PC에서 `-Only vlmxl` 로 따로 받아요. 받는 곳에 빈 공간이 406 GB 넘게 있어야 해요.
3. 서버에서는 같은 모델이 `/app/upload`, `/app/inbox`, `/app/shared/models` 에 한 벌씩, 모두 3벌(약 1.2 TB) 생겨요. `/app` SSD는 2 TB라, `b200 fetch models` 로 지문을 확인한 뒤 설치 전에 `/app/upload/models` 를 지워 2벌로 줄이세요. 설치가 끝나면 `/app/inbox/models` 도 지우세요.
4. 쓸 때는 H200 4장(141 GB × 4 = 564 GB. FP8 가중치 약 400 GB + KV 캐시)이 필요해요. 서버 2는 우리 GPU가 4장(4~7번)뿐이라 그 4장을 모두 써요. NVLink 브리지로 묶인 4장이어야 빨라요(`check_server.sh` 의 "NVLink 브리지로 묶인 GPU"). vLLM이나 SGLang으로 띄우세요.

## 목록 바꾸기

`lists/models.txt` 에 한 줄에 하나씩 `그룹  저장소  [gated]` 형식으로 적어요.

- 선택 모델을 받으려면 줄 맨 앞의 `#` 을 지우세요.
- 새 모델을 넣으려면 Hugging Face 저장소 이름(예: `facebook/dinov2-large`)을 그룹과 함께 한 줄 추가하세요. 승인이 필요한 모델이면 끝에 `gated` 를 붙이세요.
- 모델 코드가 GitHub에만 있으면 `code=https://github.com/<만든 곳>/<저장소>` 를 붙이세요. 접근 PC 스크립트가 코드 묶음도 받고, GPU 서버 스크립트가 `/app/shared/models/<만든 곳>/<모델>/code` 에 풀어요.
- 이름이 틀리면 스크립트가 `실패(이름)` 로 알려 줘요.

## 승인이 필요한 모델(gated) 받기

아래 모델은 모델 페이지에서 약관에 동의해야 받을 수 있어요. 승인은 보통 바로 되지만 몇 시간 걸릴 수도 있어요.

| 모델 | 약관 동의 페이지 |
|---|---|
| DINOv3 ViT-L | [facebook/dinov3-vitl16-pretrain-lvd1689m](https://huggingface.co/facebook/dinov3-vitl16-pretrain-lvd1689m) |
| DINOv3 ConvNeXt-L | [facebook/dinov3-convnext-large-pretrain-lvd1689m](https://huggingface.co/facebook/dinov3-convnext-large-pretrain-lvd1689m) |
| DINOv3 ViT-H+ | [facebook/dinov3-vith16plus-pretrain-lvd1689m](https://huggingface.co/facebook/dinov3-vith16plus-pretrain-lvd1689m) |
| DINOv3 7B | [facebook/dinov3-vit7b16-pretrain-lvd1689m](https://huggingface.co/facebook/dinov3-vit7b16-pretrain-lvd1689m) |
| SAM 3 | [facebook/sam3](https://huggingface.co/facebook/sam3) |
| SAM 3.1 | [facebook/sam3.1](https://huggingface.co/facebook/sam3.1) |
| Cosmos-Reason2-8B | [nvidia/Cosmos-Reason2-8B](https://huggingface.co/nvidia/Cosmos-Reason2-8B) |
| Cosmos-Reason2-32B | [nvidia/Cosmos-Reason2-32B](https://huggingface.co/nvidia/Cosmos-Reason2-32B) |

1. huggingface.co 에 로그인하고, 위 페이지마다 약관에 동의하세요. DINOv3는 모델 하나에 동의하면 같은 계열이 함께 열리는 경우가 많아요.
2. [huggingface.co/settings/tokens](https://huggingface.co/settings/tokens) 에서 **Read** 권한 토큰을 만드세요.
3. `pc\models_download.ps1` 을 실행하면 승인이 필요한 모델의 페이지 주소를 보여 주고, 브라우저로 열지 물어봐요. Enter 를 누르면 페이지가 모두 열려요. 동의한 뒤 토큰을 붙여 넣으면 돼요. 토큰은 화면과 기록 파일에 남지 않아요.
   토큰을 `.env` 의 `HF_TOKEN` 에 적어 두면 묻지 않고 바로 받아요(`docs/1_처음_설치.md` 의 "접근 PC 설정(.env)"). 이때는 1번 약관 동의를 먼저 해 두세요.

엑셀의 모델 목록 시트에서도 모델 이름을 누르면 Hugging Face 페이지가 열려요.

토큰 없이 Enter 를 누르면 승인이 필요한 모델만 건너뛰고 나머지를 받아요.

## 스크립트가 하는 일

### 접근 PC: pc\models_download.ps1

1. **점검**: uv가 있는지, Hugging Face와 파일 서버에 접속되는지, 남은 공간이 충분한지 확인해요.
2. **내려받기**: 파일마다 이어받기로 받아요. 받은 양이 늘고 있는 동안은 몇 번 끊겨도 계속 이어받고, 받은 양이 전혀 늘지 않은 채 연속 30번(약 2시간) 끊길 때만 그 모델을 포기해요.
3. **검사**: 받은 파일마다 크기와 sha256 을 Hugging Face가 알려 준 값과 비교해요. 다르면 지우고 다시 받아요.
4. **올릴 준비**: GPU 서버에서 확인할 체크섬 목록(`MANIFEST.sha256`)과 GPU 서버 스크립트를 `models` 폴더에 넣어요.

### GPU 서버: server/models_install.sh

1. **점검**: 체크섬으로 올리는 중에 손상되거나 빠진 파일이 있는지, 남은 공간이 충분한지 확인해요.
2. **옮기기**: `/app/shared/models/<만든 곳>/<모델>` 로 옮겨요.
3. **검사**: safetensors 파일을 열어 텐서 목록이 있는지 확인하고, 모델별 크기와 라이선스를 보여 줘요.
