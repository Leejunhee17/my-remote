# 공용 휠과 기초 프로그램 사용하기

B200 서버에 설치한 공용 휠과 기초 프로그램으로 내 Python 환경을 만들고, 목록을 바꾸는 방법이에요.
설치 자체는 `README.md` 의 1단계(접근 PC `pc\pack_build.ps1` → B200 서버 `server/pack_install.sh`)를 따르세요.

## 설치된 내용

| 구분 | 목록 파일 | B200 서버 위치 | 개수 |
|---|---|---|---|
| 기초 프로그램 | `lists/tools.txt` | `~/shared/tools` | 57개 (conda-forge) |
| 공용 휠 | `lists/wheels.txt` | `~/shared/wheels` | 73개, 함께 필요한 패키지까지 약 260개 |
| 공용 Python 환경 | | `~/shared/venv` | 공용 휠 전체가 설치된 환경 |

- 버전은 접근 PC에서 `pc\pack_build.ps1` 을 실행한 날 기준으로 정해져요. 정해진 버전은 B200 서버의 `~/shared/lock.txt` 와 `~/shared/pack_info.txt` 에서 확인하세요.
- B200 서버의 Ubuntu 22.04 이상(glibc 2.35 이상)에 맞춰 만들어요. 24.04 등 더 새 버전에서도 그대로 써요.
- open3d는 서버에 시스템 라이브러리 `libgl1` 이 있어야 불러올 수 있어요. 없으면 설치 스크립트가 `[주의]` 로 알려 줘요.

## 팀원이 쓰는 법

내 Python 환경 만들기 등 팀원 사용법은 `team/사용_안내.md` 에 있어요. 공용 환경(`/app/shared`)은 `admin_setup.sh` 뒤로 root 만 고칠 수 있어요.

## 목록 바꾸기

1. 접근 PC에서 `lists/tools.txt` 나 `lists/wheels.txt` 를 고치세요. `lists/wheels.txt` 에는 한 줄에 패키지 하나를 적어요.
2. `README.md` 의 1단계를 다시 실행하세요. 접근 PC 스크립트가 새 묶음 파일을 만들고, B200 서버 스크립트가 새 휠만 추가로 설치해요.
3. 기초 프로그램 목록이 바뀌었으면 B200 서버 스크립트가 `[주의]` 로 알려 줘요. 다른 사람이 기초 프로그램을 쓰지 않을 때 아래 명령으로 다시 설치하세요.

   ```bash
   # [B200 서버] root
   cd /app/inbox && tar xf b200-pack.tar && B200_REBUILD_TOOLS=1 bash pack_install.sh /app/shared
   ```

4. 엑셀의 '휠 목록', '기초 프로그램' 시트에 바뀐 내용을 적으세요.

## 패키지 하나만 빨리 추가하기

묶음 파일 전체를 다시 만들 시간이 없을 때 쓰세요. 이 패키지가 필요로 하는 다른 패키지는 함께 받지 않으니, B200 서버에서 설치가 실패하면 1단계를 다시 실행하세요.

```powershell
# [접근 PC] PowerShell, D:\b200 에서
uv tool run --from pip pip download 패키지이름 -d add --only-binary=:all: `
    --platform manylinux_2_34_x86_64 --platform manylinux_2_28_x86_64 --platform manylinux2014_x86_64 `
    --python-version 3.12 --implementation cp
tar.exe -cf add.tar add
```

`add.tar` 를 B200 서버의 `/app/inbox` 에 올린 뒤 설치하세요.

```bash
# [B200 서버] 터미널
cd /app/inbox && tar xf add.tar && cp -n add/* ~/shared/wheels/
pip install --no-index --find-links ~/shared/wheels 패키지이름
```
