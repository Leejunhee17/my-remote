# 세그멘테이션 데이터셋 받기와 구조

세그멘테이션 라벨이 있는 공개 데이터셋을 접근 PC에서 받아 GPU 서버의 `/data/autonomy_sw/datasets` 에 푸는 방법과, 풀린 뒤의 폴더 구조예요.
처음 설치는 `docs/1_처음_설치.md` 의 3단계(서버 1에서만, 접근 PC `pc\datasets_download.ps1` → GPU 서버 `server/datasets_install.sh`)를 따르세요.

## 데이터셋 목록

세그 라벨이 있는 데이터셋은 모두 받아요. RELLIS-3D, GO 는 라이다·레이더·rosbag 까지 전부 받아요. freespace·주행 가능 영역 라벨만 있는 것(ORFD, IRON, STONE, CaT), Waymo, KITTI, 비전-언어 데이터셋은 받지 않아요.
합계는 약 **770 GB** 예요(손으로 받는 RELLIS-3D 원본 rosbag 125 GB 빼고).

|---|---|---|---|---|---|---|

- 대분류는 주된 라벨 기준이에요. RELLIS-3D, GO 는 2D·3D·원시 기록에 다 걸쳐서 폴더를 2D(`rellis_2d`, `go`)와 나머지(`rellis_full`, `go_full`)로 나눴어요. ORAD-3D 는 2D 분할도 있지만 핵심이 3D 점유와 다중 과제라 따로 뒀어요.
- 라이선스는 대부분 **비상업 전용**이에요(GO·RELLIS-3D CC BY-NC-SA 3.0, Freiburg Forest 비상업 약관). ORAD-3D 는 Apache 2.0, CaSSeD 는 출처 표시만 요청해요.
- CaSSeD 받기 주소는 사이트의 "Download Dataset" 링크와 같은 것을 확인했어요(2026-11-06). 다만 사내망에서는 `www.cavs.msstate.edu` 만 차단 화면 없이 **타임아웃**이 나고(같은 학교의 `www.msstate.edu` 는 열려요), 스크립트에서는 `curl 56` 으로 한 바이트도 받지 못한 채 끊겨요. 휴대폰 모바일 데이터에서는 열려요. 그래서 스크립트는 CaSSeD 를 다른 데이터셋을 다 받은 뒤 **맨 끝에** 받아요. 사내 IT에 이 주소를 열어 달라고 하거나, 회사 밖에서 받아 아래 "손으로 받아 넣는 것" 처럼 넣으세요. 사이트에 접속되지 않을 때는 넣어 둔 `CaSSeD.tar.gz` 를 먼저 검사해서, 다 받아진 파일이면 다시 받지 않아요.
- Freiburg Forest 는 사이트의 `download_freiburg_forest_annotated.sh`·`download_freiburg_forest_raw.sh` 가 받는 조각(`.part-aa` …)을 그대로 받아 합치고, YCOR 는 AirLab 페이지의 Box 공유 링크(`cmu.box.com/s/3fngoljhcwhqf2z5cbepufh331qtesxt`) 안의 파일 하나를 받아요(둘 다 2026-11-06 확인). 예전에 적어 둔 Freiburg 주소(`…multispectral_annotated.tar.gz`)는 없는 주소였어요.
- ORAD-3D 의 ModelScope 이름(`Georgehhhh/ORAD-3D`)은 사이트가 막혀 있어 직접 확인하지 못했어요. "받지 못했어요" 가 나오면 사이트의 다운로드 링크를 브라우저로 열어 보고, 받은 파일을 아래 "손으로 받아 넣는 것" 처럼 넣으세요.
- 사내 IT에 허용을 요청할 주소: Drive(`drive.google.com`, `drive.usercontent.google.com`, `*.googleusercontent.com`), CSIRO(`data.csiro.au`, `s3.data.csiro.au`), `goose-dataset.de`, `rugd.vision`(http), `www.cavs.msstate.edu`, `deepscene.cs.uni-freiburg.de`(http 로 열면 https 로 넘어가요), `www.modelscope.cn`(과 다운로드 CDN), `cmu.box.com`·`cmu.app.box.com`·`public.boxcloud.com`(YCOR), 도구용 `pypi.org`·`files.pythonhosted.org`·`github.com`.

### 손으로 받아 넣는 것

스크립트로 받을 수 없는 것은 브라우저로 받아 아래 폴더에 **압축 파일 그대로** 넣고 `datasets_download.ps1` 을 다시 실행하세요. 넣어 둔 압축 파일을 검사해서 서버에 올릴 목록에 넣어요.

| 무엇 | 받는 곳 | 넣을 곳 |
|---|---|---|
| RELLIS-3D 원본 rosbag(Full-stack Split Raw, 시퀀스 5개, 약 125 GB)와 보정 원본(774 MB) | [RELLIS-3D README](https://github.com/unmannedlab/RELLIS-3D) 의 Drive **폴더** 링크. Drive가 폴더를 zip 여러 개로 나눠 내려 줘요 | `D:\gpu\datasets\rellis_full\` |
| CaSSeD(사내망에서 접속 안 될 때) | [CAVS 페이지](https://www.cavs.msstate.edu/resources/autonomous_dataset.php) 의 "Download Dataset" → `CaSSeD.tar.gz` | `D:\gpu\datasets\CaSSeD\` |

원본 rosbag 폴더는 같은 기록을 합친 "Full-stack Merged data"(스크립트가 받아요)와 내용이 겹쳐요. 원본이 꼭 필요할 때만 받으세요.

## 받고 설치하기

```powershell
# [접근 PC] PowerShell
cd D:\gpu
powershell -ExecutionPolicy Bypass -File .\pc\datasets_download.ps1
```

`D:\gpu\datasets` 폴더를 공용 계정의 FileZilla로 **서버 1** 의 `/app/upload` 에 올리세요. NAS에 풀려서 서버 2도 같이 써요. root 로 새로 복사해 지문을 확인한 뒤 설치하세요(지문은 접근 PC 스크립트 끝에 나와요).

**나눠 올리기:** 전부 합치면 약 750 GB라, `/app`(2 TB)에 올린 것과 복사본(`/app/inbox`)이 함께 들어가지 않아요. 데이터셋 몇 개씩 나눠 올리세요.

1. `/app/upload/datasets` 에 `MANIFEST.sha256`, `datasets_install.sh` 와 **이번에 올릴 데이터셋 폴더 몇 개**만 올려요. 예: 처음에는 `goose`, `gooseEx`, `RUGD`, `wildscenes`, 다음에는 `rellis_full`, 그다음 `ORAD-3D`.
2. 아래 두 명령으로 들여와 설치해요. 올리지 않은 데이터셋은 "이번에 올리지 않은 데이터셋(건너뛰어요)" 로 나오고, 설치된 것은 그대로 남아요.
3. 설치가 끝나면 `/app/upload/datasets`, `/app/inbox/datasets` 의 데이터셋 폴더를 지우고 다음 묶음을 올려요. 지문은 매번 같아요(`MANIFEST.sha256` 과 설치 스크립트가 같으니까요).

HIWARE로 큰 파일을 올릴 때는 FileZilla의 "이어 올리기"(같은 파일을 다시 올릴 때 **이어서** 선택)를 쓰면 끊겨도 처음부터 올리지 않아도 돼요.

```bash
# [GPU 서버 1] root
/app/admin/bin/gpu fetch datasets                  # 새로 복사하고 지문을 보여 줘요. 접근 PC 화면의 지문과 같은지
bash /app/inbox/datasets/datasets_install.sh
```

- `-Only goose,RUGD` 처럼 폴더 이름을 쉼표로 이어 붙이면 일부만 받을 수 있어요. 다 받은 것만 먼저 올려도 돼요. ORAD-3D 처럼 큰 것은 `-Only ORAD-3D` 로 따로 받으면 편해요.
- 끝나면 데이터셋마다 라벨이 몇 장 있는지 보여 줘요. "라벨을 못 찾음" 이 나오면 아래 "라벨 위치" 를 보세요.
- WildScenes 와 Google Drive 데이터셋은 아래 절에 나온 준비가 더 필요해요.

## WildScenes 접속 정보 받기

WildScenes는 CSIRO 데이터 포털의 S3 저장소에서 받아요. 접속 정보는 요청할 때마다 새로 발급되고 **약 48시간만 유효**해서, 내려받기를 시작하기 직전에 받으세요.
따로 설치할 프로그램은 없어요. 스크립트가 uv로 AWS CLI를 실행해요.

1. [CSIRO 데이터 포털의 WildScenes 페이지](https://data.csiro.au/collection/csiro:61541)에서 **Download** → **Download files via S3 Client** 를 선택하세요. 스크립트도 실행 중에 이 페이지를 브라우저로 열지 물어봐요.
2. 화면의 Download Information에서 아래 네 값을 확인하세요. 값 옆의 복사 아이콘으로 복사할 수 있어요.

   | 항목 | 예시 |
   |---|---|
   | Server | `s3.data.csiro.au` |
   | Remote Directory | `dapprd/000012345v001/` |
   | Access Key | 영문·숫자 20자 정도 |
   | Secret Access Key | 영문·숫자·기호 40자 정도 |

3. `pc\datasets_download.ps1` 을 `-WildScenes` 를 붙여 실행하세요. 스크립트가 네 값을 차례로 물어보면 붙여 넣으세요. 두 키는 화면과 기록 파일에 남지 않아요.
   네 값을 `.env` 의 `WILDSCENES_S3_SERVER`, `WILDSCENES_S3_DIR`, `WILDSCENES_ACCESS_KEY`, `WILDSCENES_SECRET_KEY` 에 적어 두면 `-WildScenes` 없이도 묻지 않고 WildScenes 까지 받아요(`docs/1_처음_설치.md` 의 "접근 PC 설정(.env)").
4. 48시간 안에 다 못 받았으면 포털에서 접속 정보를 새로 받아 같은 명령을 다시 실행하세요. 이미 받은 파일은 건너뛰어요.

### WildScenes 링크 목록으로 받기 (AWS CLI 방식이 안 될 때)

회사 프록시가 윈도우 로그인 인증을 요구하는 망에서는 AWS CLI가 `s3.data.csiro.au` 에 접속하지 못해요. 브라우저에서 `https://s3.data.csiro.au/` 가 401이나 AccessDenied라도 뜨는데 스크립트만 `curl 오류 56` 으로 실패하면 이 경우예요.
이때는 포털이 주는 파일 링크 목록을 curl로 받으세요. curl은 브라우저처럼 윈도우 로그인으로 프록시 인증을 할 수 있어요.

1. [WildScenes 페이지](https://data.csiro.au/collection/csiro:61541)에서 **Download** → **Get a list of file download links** → **Request files** 를 누르고, 약관에 동의한 뒤 **Download file links** 를 누르세요. `.txt` 파일 하나를 내려받게 돼요.
2. 그 파일 경로를 붙여 아래처럼 실행하세요. 접속 정보는 묻지 않아요. 경로를 `.env` 의 `WILDSCENES_LINKS` 에 적어 두면 붙이지 않아도 돼요.

   ```powershell
   # [접근 PC] PowerShell
   cd D:\gpu
   powershell -ExecutionPolicy Bypass -File .\pc\datasets_download.ps1 -WildScenesLinks "$env:USERPROFILE\Downloads\받은파일.txt"
   ```

- 목록에는 3D 데이터까지 모든 파일이 들어 있지만, 스크립트는 `WildScenes2d` 아래 파일만 받아요.
- 스크립트는 다 받은 파일을 `datasets\wildscenes.links_done.txt` 에 적어 두고, 다시 실행하면 남은 것만 받아요.
- 링크에는 유효 기간이 있어요. `링크가 만료됐거나 거절됐어요(401·403)` 가 나오면 1번을 다시 해서 새 목록을 받고 **바로** 같은 명령을 실행하세요. 이때는 다시 시도하지 않고 WildScenes 만 멈춰요.
- WildScenes 준비(접속 정보, 링크 목록, 저장소 접속)가 안 되면 스크립트 전체를 멈추지 않고 WildScenes 만 건너뛰고 나머지를 받아요. 결과 표에 건너뛴 이유가 나와요.
- 브라우저로 `https://s3.data.csiro.au/` 를 열었을 때 401·AccessDenied 가 뜨는 건 정상이에요. 이 저장소는 키나 서명이 붙은 주소로만 파일을 내주기 때문이에요(접속은 된다는 뜻이에요).

## Google Drive 데이터셋 받기

RELLIS-3D, TAS500, GO는 Google Drive에만 있어요(파일 50개 남짓, RELLIS-3D·GO 전부 포함). 스크립트는 gdown 같은 별도 도구 없이 curl로 받아요. rosbag·보정 파일처럼 압축이 아닌 파일은 Drive가 알려 주는 원래 파일 이름의 확장자(`.bag` 등)로 저장해요. Drive가 실제 파일을 내려 주는 주소(`drive.usercontent.google.com`)가 이어받기를 지원해서, 직접 링크 데이터셋과 똑같이 끊기면 이어받고 다 받으면 압축 손상을 검사해요. 큰 파일에서 Drive가 보여 주는 "바이러스 검사를 할 수 없음" 확인 페이지도 스크립트가 넘겨요.

- Drive에 접속되지 않으면 Drive 것은 건너뛰고 나머지를 받아요. 접근이 풀린 뒤 같은 명령을 다시 실행하세요.
- RELLIS-3D rosbag 처럼 큰 공개 파일은 Google 하루 다운로드 한도에 걸리기 쉬워요. 걸리면 다음 날 다시 실행하면 못 받은 것만 받아요.
- 점검 단계에서는 Drive 첫 페이지뿐 아니라 실제 파일 하나의 앞부분까지 받아 봐요. 첫 페이지는 열리는데 파일 받기만 막힌 망을 미리 찾아내기 위해서예요.
- 받다가 403 같은 거절이 나오면 몇 시간씩 다시 시도하지 않고, 바로 이유를 가려 알려 줘요.

| 화면에 나오는 이유 | 뜻 | 할 일 |
|---|---|---|
| 회사 프록시나 보안 장비가 막았어요 | Google이 아니라 회사 장비가 거절했어요. 응답 머리글에 Google 표시가 없는 것으로 알 수 있어요 | 사내 IT에 `drive.usercontent.google.com` 파일 다운로드 허용을 요청하세요. 화면의 Server와 페이지 제목을 같이 알려 주세요 |

## 스크립트가 하는 일

### 접근 PC: pc\datasets_download.ps1

1. **점검**: uv, curl, tar가 있는지, 사이트마다 인터넷 접속이 되는지, WildScenes 접속 정보가 맞는지, 남은 공간이 충분한지 확인해요. Google Drive에 접속되는지도 확인해서 알려 줘요. Drive가 막혀 있어도 멈추지 않고 나머지를 받아요.
2. **내려받기**: 인터넷이 끊기면 기다렸다가 이어서 받아요. 받은 양이 늘고 있는 동안은 몇 번 끊겨도 계속 이어받아요. 받은 양이 전혀 늘지 않은 채 연속 30번 끊길 때만(기다리는 시간이 30초씩 늘어 최대 5분, 합쳐서 약 2시간) 그 파일을 포기하고 다음 파일로 넘어가요.
   - 직접 링크(GOOSE, GOOSE-Ex, RUGD, YCOR, CaSSeD, Freiburg Forest): `curl -C -` 로 이어받아요. Freiburg Forest 는 512 MB 조각마다 이어받고, 다 받으면 하나로 합쳐 검사한 뒤 조각을 지워요(합치는 동안 같은 크기의 빈 공간이 더 필요해요). YCOR 는 받을 때마다 Box 가 새 임시 주소로 넘겨 줘서 이어받기도 돼요.
   - ORAD-3D: uv 로 `modelscope download` 를 실행해요. 다시 실행하면 받은 데까지 이어서 받고, 다 받으면 파일마다 체크섬을 적어요.
   - WildScenes: `aws s3 sync` 가 이미 받은 파일을 건너뛰어요. 끝나면 빠진 파일이 없는지 한 번 더 확인해요.
   - Google Drive 데이터셋: Drive에 접속되면 curl로 이어받아요.
   - 직접 넣어 둔 압축 파일(위 "손으로 받아 넣는 것")이 있으면 그것도 검사해요.
3. **검사**: 압축 파일을 끝까지 읽어 손상 여부를 확인해요. 받은 파일이 손상됐으면 지우고 처음부터 다시 받아요.
4. **올릴 준비**: GPU 서버에서 확인할 체크섬 목록(`MANIFEST.sha256`)과 GPU 서버 스크립트를 `datasets` 폴더에 넣어요.
5. **결과**: 데이터셋별 결과와 GPU 서버에 올릴 것을 보여 줘요.

검사까지 끝난 파일 옆에는 `.ok` 파일이 생겨요. 다시 실행하면 `.ok` 가 있는 파일은 건너뛰어요. 처음부터 다시 받으려면 그 파일과 `.ok` 파일을 지우고 다시 실행하세요.
`-Only goose,RUGD` 처럼 폴더 이름을 쉼표로 이어 붙이면 일부만 받을 수 있어요. 다 받은 것만 먼저 GPU 서버에 올려도 돼요.

### GPU 서버: server/datasets_install.sh

1. **점검**: 이번에 올린 데이터셋 폴더만 골라 체크섬으로 손상되거나 빠진 파일이 있는지, WildScenes 파일 수가 맞는지, 남은 공간이 충분한지 확인해요. 안 올린 데이터셋은 건너뛰어요(나눠 올리기).
2. **풀기**: `/data/autonomy_sw/datasets/<폴더>` 아래, 압축이 있던 폴더에 풀어요. rosbag 처럼 압축이 아닌 파일은 같은 경로에 그대로 둬요. 이미 푼 파일은 건너뛰어요.
3. **검사**: 아래 "라벨 위치" 에 라벨이 몇 장 있는지 세고, RUGD 색상표 파일이 있는지 확인해요. 라벨 위치를 정하지 않은 데이터셋(`rellis_full`, `go_full`, `ORAD-3D`, `CaSSeD`, `freiburg_forest`, `ycor`)은 파일 수만 보여 줘요.

## 라벨 위치

데이터셋마다 라벨 파일이 있는 위치예요. 설치 스크립트가 이 위치에서 라벨을 세어 보여 줘요. 학습 코드는 이 위치를 기준으로 경로를 정하면 돼요.
"라벨을 못 찾음" 이 나오면 압축 안의 폴더가 한 단계 더 있거나 없는 경우가 대부분이에요. 화면의 "지금 구조" 를 보고 아래 위치에 맞게 폴더를 옮기세요.
