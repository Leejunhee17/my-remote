# 세그멘테이션 데이터셋 받기와 구조

세그멘테이션(픽셀마다 클래스를 매기는 일) 라벨이 있는 공개 데이터셋을 접근 PC(인터넷이 되는 윈도우 PC)에서 받아 GPU 서버의 `/data/autonomy_sw/datasets` 에 푸는 방법과, 풀린 뒤의 폴더 구조예요.
4단계(데이터셋 넣기)는 **사용자** 몫이에요. 관리자가 1·2단계(준비, 기초 프로그램)를 끝낸 뒤라면 언제든 이 문서대로 하면 돼요. root 권한은 필요 없어요.

## 데이터셋 목록

세그멘테이션(세그) 라벨이 있는 데이터셋은 모두 받아요. RELLIS-3D, GO 는 라이다·레이더·rosbag(ROS 로봇의 센서 기록 파일)까지 전부 받아요. freespace(빈 공간)·주행 가능 영역 라벨만 있는 것(ORFD, IRON, STONE, CaT), Waymo, KITTI, 비전-언어 데이터셋은 받지 않아요.
합계는 약 **770 GB** 예요(손으로 받는 RELLIS-3D 원본 rosbag 125 GB 빼고).

- 대분류는 주된 라벨 기준이에요. RELLIS-3D, GO 는 2D·3D·원시 기록에 다 걸쳐서 폴더를 2D(`rellis_2d`, `go`)와 나머지(`rellis_full`, `go_full`)로 나눴어요. ORAD-3D 는 2D 분할도 있지만 핵심이 3D 점유와 다중 과제라 따로 뒀어요.
- 라이선스는 대부분 **비상업 전용**이에요(GO·RELLIS-3D CC BY-NC-SA 3.0, Freiburg Forest 비상업 약관). ORAD-3D 는 Apache 2.0, CaSSeD 는 출처 표시만 요청해요.
- CaSSeD 받기 주소는 사이트의 "Download Dataset" 링크와 같은 것을 확인했어요(2026-11-06). 다만 사내망에서는 `www.cavs.msstate.edu` 만 차단 화면 없이 **타임아웃**이 나고(같은 학교의 `www.msstate.edu` 는 열려요), 스크립트에서도 한 바이트도 받지 못한 채 끊겨요. 휴대폰 모바일 데이터에서는 열려요. 그래서 스크립트는 CaSSeD 를 다른 데이터셋을 다 받은 뒤 **맨 끝에** 받아요. 사내망에서 `cmu.box.com` 이 막힌 YCOR 도 같이 맨 끝으로 미뤘어요(YCOR → CaSSeD 순서). 맨 끝의 둘은 한 바이트도 못 받은 채 3번 끊기면(`-LateTries`, 기본 3) 바로 넘어가서 몇 시간씩 붙잡히지 않아요. 받아지기 시작하면 끝까지 이어받아요. 사내 IT에 이 주소를 열어 달라고 하거나, 회사 밖에서 받아 아래 "손으로 받아 넣는 것" 처럼 넣으세요. 사이트에 접속되지 않을 때는 넣어 둔 `CaSSeD.tar.gz` 를 먼저 검사해서, 다 받아진 파일이면 다시 받지 않아요.
- Freiburg Forest 는 사이트의 `download_freiburg_forest_annotated.sh`·`download_freiburg_forest_raw.sh` 가 받는 조각(`.part-aa` …)을 그대로 받아 합치고, YCOR 는 AirLab 페이지의 Box 공유 링크(`cmu.box.com/s/3fngoljhcwhqf2z5cbepufh331qtesxt`) 안의 파일 하나를 받아요(둘 다 2026-11-06 확인). 예전에 적어 둔 Freiburg 주소(`…multispectral_annotated.tar.gz`)는 없는 주소였어요.
- ORAD-3D 의 ModelScope 이름(`Georgehhhh/ORAD-3D`)은 사이트가 막혀 있어 직접 확인하지 못했어요. "받지 못했어요" 가 나오면 사이트의 다운로드 링크를 브라우저로 열어 보고, 받은 파일을 아래 "손으로 받아 넣는 것" 처럼 넣으세요.
- 사내 IT에 허용을 요청할 주소: Drive(`drive.google.com`, `drive.usercontent.google.com`, `*.googleusercontent.com`), CSIRO(`data.csiro.au`, `s3.data.csiro.au`), `goose-dataset.de`, `rugd.vision`(http), `www.cavs.msstate.edu`, `deepscene.cs.uni-freiburg.de`(http 로 열면 https 로 넘어가요), `www.modelscope.cn`·`cdn-lfs-cn-1.modelscope.cn`(ORAD-3D. 파일 목록은 앞 주소에서, 실제 파일은 뒤 주소에서 받아요), `cmu.box.com`·`cmu.app.box.com`·`public.boxcloud.com`(YCOR. 사내망에서 막혀 있어요), 도구용 `pypi.org`·`files.pythonhosted.org`·`github.com`.

### 손으로 받아 넣는 것

스크립트로 받을 수 없는 것은 브라우저로 받아 아래 폴더에 **압축 파일 그대로** 넣고 `datasets_download.ps1` 을 다시 실행하세요. 넣어 둔 압축 파일을 검사해서 서버에 올릴 목록에 넣어요.

| 무엇 | 받는 곳 | 넣을 곳 |
|---|---|---|
| RELLIS-3D 원본 rosbag(Full-stack Split Raw, 시퀀스 5개, 약 125 GB)와 보정 원본(774 MB) | [RELLIS-3D README](https://github.com/unmannedlab/RELLIS-3D) 의 Drive **폴더** 링크. Drive가 폴더를 zip 여러 개로 나눠 내려 줘요 | `D:\gpu\datasets\rellis_full\` |
| CaSSeD(사내망에서 접속 안 될 때) | [CAVS 페이지](https://www.cavs.msstate.edu/resources/autonomous_dataset.php) 의 "Download Dataset" → `CaSSeD.tar.gz` | `D:\gpu\datasets\CaSSeD\` |

원본 rosbag 폴더는 같은 기록을 합친 "Full-stack Merged data"(스크립트가 받아요)와 내용이 겹쳐요. 원본이 꼭 필요할 때만 받으세요.

## 받아서 서버에 넣기

```powershell
# [접근 PC] PowerShell
cd D:\gpu
powershell -ExecutionPolicy Bypass -File .\pc\datasets_download.ps1
```

**규칙은 하나예요. 데이터셋은 `/data/autonomy_sw/datasets/<데이터셋 폴더>/` 에 둬요.** 아래 스크립트는 그 자리에 맞춰 넣어 주는 도구라, 손으로 옮겨도 자리만 맞으면 괜찮아요.

1. `D:\gpu\datasets` 폴더를 공용 계정(팀원이 같이 쓰는 서버 계정)으로 접속한 FileZilla(파일 전송 프로그램)로 NAS 의 `/data/autonomy_sw/inbox` 에 올려요(`/data/autonomy_sw/inbox/datasets` 가 돼요). inbox 에 다른 파일·폴더가 있어도 괜찮아요.
2. 공용 계정으로 서버에 접속해(PuTTY) 아래 명령을 실행해요. 두 서버 중 한 곳에서 한 번만 하면 돼요. NAS 에 풀려서 다른 서버에서도 바로 보여요.

```bash
# [GPU 서버 1 또는 2] 공용 계정, 한 곳에서만
bash /data/autonomy_sw/inbox/datasets/datasets_unpack.sh
```

| | |
|---|---|
| 올리는 곳 | NAS `/data/autonomy_sw/inbox/datasets/` |
| 결과를 두는 곳 | NAS `/data/autonomy_sw/datasets/<데이터셋 폴더>/`. 압축은 원래 들어 있던 폴더 안에 풀어요(예: `goose/goose_2d_train.zip` → `datasets/goose/` 안) |
| 기록 파일 | 올린 곳의 `datasets_unpack_<날짜_시각>.log` |

**나눠 올리기:** 전부 합치면 약 770 GB예요. 한 번에 올리기 부담스러우면 데이터셋 몇 개씩 나눠 올려도 돼요.

1. NAS 의 `/data/autonomy_sw/inbox/datasets` 에 `MANIFEST.sha256`(파일마다 체크섬을 적은 목록), `datasets_unpack.sh` 와 **이번에 올릴 데이터셋 폴더 몇 개**만 올려요. 예: 처음에는 `goose`, `gooseEx`, `RUGD`, `wildscenes`, 다음에는 `rellis_full`, 그다음 `ORAD-3D`.
2. 위 명령을 실행해요. 올리지 않은 데이터셋은 "이번에 올리지 않은 데이터셋(건너뛰어요)" 로 나오고, 이미 푼 것은 그대로 남아요.
3. 다 풀면 inbox 에 남은 그 데이터셋 폴더를 지우고 다음 묶음을 올려요. 압축이 아닌 파일(rosbag, WildScenes 사진 등)은 풀 때 제자리로 옮겨서 inbox 에 남지 않아요.

`/data/autonomy_sw/datasets` 에 원래 있던 다른 폴더는 건드리지 않아요. 넣으려는 데이터셋과 이름이 같은 폴더가 이미 있는데 스크립트가 푼 것이 아니면, 덮어쓰지 않고 그 데이터셋만 건너뛰며 `[주의]` 로 알려요. 스크립트가 푼 폴더에는 `.gpu_placed` 파일이 있어요.

두 서버에서 동시에 실행하지는 마세요. 같은 NAS 폴더에 함께 쓰면 꼬일 수 있어요. 한쪽이 끝난 뒤 다른 쪽에서 다시 실행하는 건 괜찮아요.

HIWARE(서버에 접속할 때 거치는 사내 접속 관리 시스템)를 거쳐 큰 파일을 올릴 때는 FileZilla의 "이어 올리기"(같은 파일을 다시 올릴 때 **이어서** 선택)를 쓰면 끊겨도 처음부터 올리지 않아도 돼요.

- `-Only goose,RUGD` 처럼 폴더 이름을 쉼표로 이어 붙이면 일부만 받을 수 있어요. 다 받은 것만 먼저 올려도 돼요. ORAD-3D 처럼 큰 것은 `-Only ORAD-3D` 로 따로 받으면 편해요.
- 끝나면 데이터셋마다 라벨이 몇 장 있는지 보여 줘요. "라벨을 못 찾음" 이 나오면 아래 "라벨 위치" 를 보세요.
- WildScenes 와 Google Drive 데이터셋은 아래 절에 나온 준비가 더 필요해요.

## WildScenes 링크 목록으로 받기

WildScenes는 CSIRO 데이터 포털이 주는 **파일 링크 목록(.txt)** 으로 받아요. 링크마다 서명이 들어 있어서 따로 접속 정보(키)가 필요 없어요. 예전의 S3(아마존 클라우드 저장소) 접속 정보(AWS CLI) 방식은 뺐어요.

1. [WildScenes 페이지](https://data.csiro.au/collection/csiro:61541)에서 **Download** → **Get a list of file download links** → **Request files** 를 누르고, 약관에 동의한 뒤 **Download file links** 를 누르세요. `.txt` 파일 하나를 내려받게 돼요.
2. 그 파일 경로를 붙여 아래처럼 실행하세요. 경로를 `.env` 의 `WILDSCENES_LINKS` 에 적어 두면 붙이지 않아도 돼요(`docs/1_처음_설치.md` 의 "접근 PC 설정(.env)").

   ```powershell
   # [접근 PC] PowerShell
   cd D:\gpu
   powershell -ExecutionPolicy Bypass -File .\pc\datasets_download.ps1 -WildScenesLinks "$env:USERPROFILE\Downloads\받은파일.txt"
   ```

- 목록에는 3D 데이터까지 모든 파일이 들어 있지만, 스크립트는 `WildScenes2d` 아래 파일만 받아요.
- 받는 도구는 **aria2c** 예요(목록이 aria2 형식이라 그대로 맞고, 16개씩 동시에 받아 빨라요). 처음 실행할 때 공식 윈도우판(1.37.0)을 GitHub 에서 받아 지문을 확인한 뒤 `D:\gpu\tools\aria2\` 에 둬요(git 에는 올라가지 않아요). GitHub 에서 못 받으면 WildScenes 는 건너뛰어요(다른 데이터셋도 aria2c 로 받아서, 점검 단계에서 [문제] 로 알려 줘요).
- 사내망은 인증서 폐기 확인 서버(CRL·OCSP)에 닿지 않아서, 윈도우 curl 은 `curl: (35) … CRYPT_E_NO_REVOCATION_CHECK` 로 끊겨요(브라우저는 그냥 넘어가요). 그래서 스크립트는 curl 을 쓰지 않아요. aria2c 윈도우판은 인증서를 검증하면서 이 경우만 넘어가게 만들어져 있어서, 보안 확인을 끄지 않고도 받아져요(2026-11-06 확인).
- 스크립트는 다 받은 파일을 `datasets\wildscenes.links_done.txt` 에 적어 두고, 다시 실행하면 남은 것만 받아요.
- 링크에는 유효 기간이 있어요. `링크가 만료됐거나 거절됐어요(401·403)` 가 나오면 1번을 다시 해서 새 목록을 받고 **바로** 같은 명령을 실행하세요. 이때는 다시 시도하지 않고 WildScenes 만 멈춰요.
- WildScenes 준비(접속 정보, 링크 목록, 저장소 접속)가 안 되면 스크립트 전체를 멈추지 않고 WildScenes 만 건너뛰고 나머지를 받아요. 결과 표에 건너뛴 이유가 나와요.
- 링크가 브라우저(시크릿 창 포함)로는 받아지는데 스크립트만 401·403 이면 아래를 실행하세요. 링크 하나를 .NET(브라우저와 같은 방법)으로 앞 1 KB 만 요청해 보고, 받기 스크립트와 같은 aria2c 로 끝까지 받아 본 뒤, 결과를 `reports\wildscenes_check_공유용_<날짜>.txt` 에 적어요. 그다음 git 으로 올릴지 물어보고 올려요. 서명·키, 프록시 주소, 사내 IP 는 가려서 적어요. 접근 PC 전체(프로그램·`.env`·다른 사이트·디스크)는 `pc\check.ps1` 로 점검해요(`docs/1_처음_설치.md` 의 "접근 PC 점검").

   ```powershell
   # [접근 PC] PowerShell
   cd D:\gpu
   git pull
   powershell -ExecutionPolicy Bypass -File .\pc\wildscenes_check.ps1      # .env 의 WILDSCENES_LINKS 목록. 다른 파일은 -Links <경로>
   ```

- 브라우저로 `https://s3.data.csiro.au/` 를 열었을 때 401·AccessDenied 가 뜨는 건 정상이에요. 이 저장소는 키나 서명이 붙은 주소로만 파일을 내주기 때문이에요(접속은 된다는 뜻이에요).

## Google Drive 데이터셋 받기

RELLIS-3D, TAS500, GO는 Google Drive에만 있어요(파일 50개 남짓, RELLIS-3D·GO 전부 포함). 스크립트는 aria2c 로 받아요(쿠키를 이어 가며 받아요). rosbag·보정 파일처럼 압축이 아닌 파일은 Drive가 알려 주는 원래 파일 이름의 확장자(`.bag` 등)로 저장해요. Drive가 실제 파일을 내려 주는 주소(`drive.usercontent.google.com`)가 이어받기를 지원해서, 직접 링크 데이터셋과 똑같이 끊기면 이어받고 다 받으면 압축 손상을 검사해요. 큰 파일에서 Drive가 보여 주는 "바이러스 검사를 할 수 없음" 확인 페이지도 스크립트가 넘겨요.

- Drive에 접속되지 않으면 Drive 것은 건너뛰고 나머지를 받아요. 접근이 풀린 뒤 같은 명령을 다시 실행하세요.
- RELLIS-3D rosbag 처럼 큰 공개 파일은 Google 하루 다운로드 한도에 걸리기 쉬워요. 걸리면 다음 날 다시 실행하면 못 받은 것만 받아요. 매일 손으로 실행하기 번거로우면 아래 "자동 받기" 를 켜 두세요.
- 점검 단계에서는 Drive 첫 페이지뿐 아니라 실제 파일 하나의 앞부분까지 받아 봐요. 첫 페이지는 열리는데 파일 받기만 막힌 망을 미리 찾아내기 위해서예요. 큰 파일의 하루 한도를 쓰지 않게 작은 파일(1 GB 이하)로 시험해요.
- 한도는 **파일마다** 따로예요. 한 파일이 한도에 걸려도 나머지 Drive 파일은 계속 받아요. 걸린 파일만 다음 날 같은 명령으로 다시 받으면 돼요.
- 받다가 403 같은 거절이 나오면 몇 시간씩 다시 시도하지 않고, 바로 이유를 가려 알려 줘요.

| 화면에 나오는 이유 | 뜻 | 할 일 |
|---|---|---|
| 회사 프록시나 보안 장비가 막았어요 | Google이 아니라 회사 장비가 거절했어요. 응답 헤더(머리글)에 Google 표시가 없는 것으로 알 수 있어요 | 사내 IT에 `drive.usercontent.google.com` 파일 다운로드 허용을 요청하세요. 화면의 Server와 페이지 제목을 같이 알려 주세요 |
| Google 다운로드 한도 초과 | 최근 이 파일을 받은 사람이 많아 Google이 하루쯤 막았어요. 공개 데이터셋에서 자주 생겨요 | 다음 날 다시 실행하세요. `-Auto` 를 붙여 실행해 두면 알아서 다시 받아요. 급하면 브라우저에서 로그인해 "내 드라이브에 사본 만들기"를 한 뒤 사본을 받아 넣으세요 |
| 로그인이나 접근 권한이 필요해요 | 공유 설정이 바뀌었어요 | 브라우저에서 로그인해 받아 넣으세요 |
| Google이 이 망의 요청을 자동 요청으로 보고 막았어요 | 회사 전체가 같은 IP로 나가는 망에서 생겨요 | 몇 시간 뒤 다시 하거나 브라우저로 받아 넣으세요 |

### 자동 받기

자동 받기는 못 받은 파일을 몇 시간마다 알아서 다시 받는 기능이에요.

Google 한도는 자정 같은 정해진 시각에 풀리지 않아요. 한도에 걸리고 나서 하루쯤 지나야 풀리는데, 정확히 언제 풀리는지는 Google이 알려 주지 않아요. 그래서 하루에 한 번이 아니라 **6시간마다** 다시 받아 봐요. 이렇게 하면 한도가 풀리고 늦어도 6시간 안에 받기 시작해요. 다시 받을 때는 못 받은 파일만 받고, 아직 한도에 걸린 파일은 바로 넘어가요. 그래서 자주 돌려도 괜찮아요.

`-Auto` 를 붙여 실행하면 지금 바로 받지는 않아요. 대신 윈도우 작업 스케줄러(정해진 시각에 프로그램을 대신 실행해 주는 윈도우 기능)에 자동 받기를 등록해요. `-Only` 를 붙이지 않으면 Google Drive 데이터셋(RELLIS-3D, TAS500, GO)만 받아요.

```powershell
# [접근 PC] PowerShell
cd D:\gpu
powershell -ExecutionPolicy Bypass -File .\pc\datasets_download.ps1 -Auto
```

- 처음 실행은 등록하고 6시간 뒤예요. 간격은 `-AutoHours 4` 처럼 바꿀 수 있어요. `-AutoDays`(기본 14일)가 지나면 다 받지 못했어도 멈춰요.
- 실패한 파일도 없고, Drive 접속이 안 돼 건너뛴 파일도 없으면 자동 받기가 저절로 꺼져요.
- 다른 데이터셋도 같이 자동으로 받으려면 `-Only` 로 고르세요(예: `-Auto -Only rellis_full,ORAD-3D`). 사내망에서 막힌 YCOR·CaSSeD 를 넣으면 매번 실패해서 `-AutoDays` 가 지날 때까지 꺼지지 않아요.
- PC가 켜져 있고 윈도우에 로그인돼 있어야 해요(화면 잠금은 괜찮아요). 절전 상태면 깨워서 실행하고, 꺼져 있었으면 켜질 때 바로 실행해요. 실행되면 PowerShell 창이 떠요. 앞서 시작한 받기가 아직 끝나지 않았으면 이번 실행은 건너뛰어요.
- 진행 상황은 `datasets\download.log` 맨 끝에 쌓여요.
- 끄려면 `-AutoOff` 를 붙여 실행하세요. 회사 정책으로 작업 스케줄러가 막혀 있으면 등록에 실패하고, 그 이유가 화면에 나와요.

```powershell
powershell -ExecutionPolicy Bypass -File .\pc\datasets_download.ps1 -AutoOff
```

## 스크립트가 하는 일

### 접근 PC: pc\datasets_download.ps1

1. **점검**: uv(파이썬 도구 관리 프로그램), tar, aria2c(처음이면 받아서 준비)가 있는지, 사이트마다 인터넷 접속이 되는지, WildScenes 링크 목록을 읽을 수 있는지, 남은 공간이 충분한지 확인해요. Google Drive에 접속되는지도 확인해서 알려 줘요. Drive가 막혀 있어도 멈추지 않고 나머지를 받아요.
2. **내려받기**: 인터넷이 끊기면 기다렸다가 이어서 받아요. 받은 양이 늘고 있는 동안은 몇 번 끊겨도 계속 이어받아요. 받은 양이 전혀 늘지 않은 채 끊기면 **한 번만 맨 뒤로 미뤄요.** 처음에는 다시 해 보지 않고 바로 미루고 다음 파일로 넘어가요. 다른 것을 다 받은 뒤 미룬 파일을 다시 받아 보고, 그때도 연속 5번(기다리는 시간이 30초씩 늘어 최대 2분, 합쳐서 약 5분) 끊기면 실패로 남겨요. 사이트에 아예 접속되지 않으면 기다리지 않고 바로 미뤄요. Google Drive 하루 한도나 권한 문제는 같은 날 다시 해도 같아서 미루지 않아요. 일반 사이트는 연결 4개로 나눠 받아서 빨라요(안 되면 그 파일만 1개로 다시 받아요). Google Drive 와 Box 는 여러 연결로 받으면 한도에 빨리 걸리거나 거절돼서 1개로 받아요. Drive 에서 한 바이트도 더 못 받고 끊기면 한도에 걸린 건지 확인해서, 한도면 바로 알려 줘요. 못 받은 파일은 같은 명령을 다시 실행하거나 자동 받기(`-Auto`)로 나중에 이어받아요.
   - 직접 링크(GOOSE, GOOSE-Ex, RUGD, YCOR, CaSSeD, Freiburg Forest): aria2c 로 이어받아요. 없는 주소(404)·거절(403)이면 다시 시도하지 않고 바로 알려 줘요. Freiburg Forest 는 512 MB 조각마다 이어받고, 다 받으면 하나로 합쳐 검사한 뒤 조각을 지워요(합치는 동안 같은 크기의 빈 공간이 더 필요해요). YCOR 는 받을 때마다 Box 가 새 임시 주소로 넘겨 줘서 이어받기도 돼요.
   - ORAD-3D: uv 로 `modelscope download` 를 실행해요. 다시 실행하면 받은 데까지 이어서 받고, 다 받으면 파일마다 체크섬(파일 내용이 그대로인지 확인하는 값)을 적어요.
   - WildScenes: 링크 목록의 `WildScenes2d` 파일을 aria2c 로 16개씩 받아요. 다 받은 파일은 `wildscenes.links_done.txt` 에 적어 다시 실행하면 건너뛰어요.
   - Google Drive 데이터셋: Drive에 접속되면 aria2c 로 이어받아요.
   - 직접 넣어 둔 압축 파일(위 "손으로 받아 넣는 것")이 있으면 그것도 검사해요.
3. **검사**: 압축 파일을 끝까지 읽어 손상됐는지 확인해요. 받은 파일이 손상됐으면 지우고 처음부터 다시 받아요.
4. **올릴 준비**: GPU 서버에서 확인할 체크섬 목록(`MANIFEST.sha256`)과 GPU 서버 스크립트를 `datasets` 폴더에 넣어요.
5. **결과**: 데이터셋별 결과와 GPU 서버에 올릴 것을 보여 줘요.

검사까지 끝난 파일 옆에는 `.ok` 파일이 생겨요. 다시 실행하면 `.ok` 가 있는 파일은 건너뛰어요. 처음부터 다시 받으려면 그 파일과 `.ok` 파일을 지우고 다시 실행하세요.
`-Only goose,RUGD` 처럼 폴더 이름을 쉼표로 이어 붙이면 일부만 받을 수 있어요. 다 받은 것만 먼저 GPU 서버에 올려도 돼요.

### GPU 서버: server/datasets_unpack.sh

1. **점검**: 이번에 올린 데이터셋 폴더만 골라 빠진 파일이 없는지, 남은 공간이 충분한지 확인해요. 안 올린 데이터셋과 같은 이름의 남의 폴더가 있는 데이터셋은 건너뛰어요.
2. **풀기**: 파일마다 체크섬을 확인한 뒤 `/data/autonomy_sw/datasets/<폴더>` 아래, 압축이 있던 폴더에 풀어요. rosbag 처럼 압축이 아닌 파일은 같은 경로로 옮겨요. 체크섬이 맞지 않는 파일(받거나 올리다 깨진 것)은 넣지 않고 `[문제]` 로 알려요. 이미 푼 파일은 건너뛰어요.
3. **검사**: 아래 "라벨 위치" 에 라벨이 몇 장 있는지 세고, RUGD 색상표 파일이 있는지 확인해요. 라벨 위치를 정하지 않은 데이터셋(`rellis_full`, `go_full`, `ORAD-3D`, `CaSSeD`, `freiburg_forest`, `ycor`)은 파일 수만 보여 줘요.

## 라벨 위치
