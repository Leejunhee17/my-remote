# 사전학습 모델 받기와 쓰기

야지(오프로드) 주행의 세그멘테이션, 주행 가능 영역, 깊이 추정, VLM 연구에 쓸 Hugging Face 사전학습 모델을 B200 서버에 준비하는 방법이에요.
받기와 설치는 `README.md` 의 3단계(접근 PC `pc\models_download.ps1` → B200 서버 `server/models_install.sh`)를 따르세요.
받은 모델은 B200 서버의 `~/shared/models/<만든 곳>/<모델>` 에 있어서, 인터넷 없이 경로로 불러 쓸 수 있어요.

## 받는 모델

목록은 `lists/models.txt` 에 있어요. 그룹마다 기본으로 받는 모델과, 앞에 `#` 이 붙어 받지 않는 선택 모델이 있어요. 크기는 2026-10-27 기준 대략 값이에요.

오프로드 장면은 풀, 나무, 흙, 물웅덩이, 바위가 대부분이에요. 그래서 도시 도로(Cityscapes)로 학습한 모델보다 자연물 클래스가 많은 ADE20K, Mapillary로 학습한 모델을 기본으로 골랐어요. Cityscapes 모델은 선택 모델로 남겨 뒀어요.

| 그룹 | 내용 | 기본 모델 | 크기 |
|---|---|---|---|
| `seg` | GOOSE, RELLIS-3D, RUGD에 미세조정할 출발점 | **GOOSE-M2F**(GOOSE로 학습, 코드 포함)와 그 바탕 Mask2Former(Cityscapes), EoMT(ADE20K), Mask2Former Swin-L(ADE20K, Mapillary), SegFormer-B5(ADE20K) | 약 8.1 GB |
| `enc` | segmentation-models-pytorch(smp) 인코더 가중치 | mit_b5, convnext_large, resnet50 | 약 1.2 GB |
| `backbone` | 밀집 특징 기반 모델. 주행 가능 영역(traversability) 연구 대부분이 이 특징 위에 가벼운 헤드를 올려요 | DINOv3(ViT-L, ViT-H+, ConvNeXt-L), DINOv2-L, C-RADIOv4-H. GOOSE 2026 챌린지 1·2위가 DINOv3 ViT-L, ViT-H+를 썼어요 | 약 9.5 GB |
| `depth` | 깊이와 기하. 경사, 단차, 장애물 높이를 구할 때 써요 | Depth Anything 3(미터 깊이, 상대 깊이), Depth Anything V2(상대 깊이, 실외 미터 깊이) | 약 5.2 GB |
| `openvocab` | 텍스트로 분할·검출. 라벨 없는 주행 영상에 "mud", "puddle", "tall grass" 같은 단어로 의사 라벨을 만들어요 | SAM 3, SAM 2.1, Grounding DINO, OWLv2, SigLIP2, CLIPSeg | 약 12.2 GB |
| `vlm` | 장면 이해와 주행 판단 | Qwen3-VL-8B, Cosmos-Reason2-8B(물리 세계·주행 추론), Qwen3.5-9B | 약 54.3 GB |
| `vlmseg` | 말로 지시하면 분할까지 하는 VLM | Sa2VA(Qwen3-VL-4B + SAM3, + SAM2) | 약 41 GB |

기본 모델을 모두 받으면 약 132 GB예요. `-Only seg,enc,backbone` 처럼 그룹을 골라 나눠 받을 수 있어요.

- 같은 가중치가 여러 형식으로 있으면 safetensors 만 받아요. ONNX, TensorFlow, 예시 이미지는 받지 않아요.
- 모델마다 받은 시점의 커밋, 파일 수, 라이선스를 `b200_model.json` 에 남겨요.
- 라이선스가 모델마다 달라요. DINOv3, SAM 3, Cosmos-Reason2는 자체 라이선스예요. NVIDIA SegFormer와 Depth Anything V2 Large는 비상업 라이선스예요. 쓰기 전에 모델 페이지에서 확인하세요.
- 오프로드 데이터셋으로 학습한 공개 모델은 아직 적어요. 기본으로 받는 것은 GOOSE-M2F 하나예요(ICRA 2026 GOOSE 2D 챌린지 3위, 64클래스). GOOSE·RELLIS-3D로 학습한 mmsegmentation 체크포인트 모음(`roboticslaburjc-org/cross-dataset-visual-offroad-segmentation`)을 선택 모델로 넣어 뒀어요. 용량이 크고 mmsegmentation이 있어야 불러올 수 있어요.

## 목록 바꾸기

`lists/models.txt` 에 한 줄에 하나씩 `그룹  저장소  [gated]` 형식으로 적어요.

- 선택 모델을 받으려면 줄 맨 앞의 `#` 을 지우세요.
- 새 모델을 넣으려면 Hugging Face 저장소 이름(예: `facebook/dinov2-large`)을 그룹과 함께 한 줄 추가하세요. 승인이 필요한 모델이면 끝에 `gated` 를 붙이세요.
- 모델 코드가 GitHub에만 있으면 `code=https://github.com/<만든 곳>/<저장소>` 를 붙이세요. 접근 PC 스크립트가 코드 묶음도 받고, B200 서버 스크립트가 `~/shared/models/<만든 곳>/<모델>/code` 에 풀어요.
- 이름이 틀리면 스크립트가 `실패(이름)` 로 알려 줘요.

## 승인이 필요한 모델(gated) 받기

아래 모델은 모델 페이지에서 약관에 동의해야 받을 수 있어요. 승인은 보통 바로 되지만 몇 시간 걸릴 수도 있어요.

| 모델 | 약관 동의 페이지 |
|---|---|
| DINOv3 ViT-L | [facebook/dinov3-vitl16-pretrain-lvd1689m](https://huggingface.co/facebook/dinov3-vitl16-pretrain-lvd1689m) |
| DINOv3 ConvNeXt-L | [facebook/dinov3-convnext-large-pretrain-lvd1689m](https://huggingface.co/facebook/dinov3-convnext-large-pretrain-lvd1689m) |
| DINOv3 ViT-H+ | [facebook/dinov3-vith16plus-pretrain-lvd1689m](https://huggingface.co/facebook/dinov3-vith16plus-pretrain-lvd1689m) |
| SAM 3 | [facebook/sam3](https://huggingface.co/facebook/sam3) |
| Cosmos-Reason2-8B | [nvidia/Cosmos-Reason2-8B](https://huggingface.co/nvidia/Cosmos-Reason2-8B) |

1. huggingface.co 에 로그인하고, 위 페이지마다 약관에 동의하세요. DINOv3는 모델 하나에 동의하면 같은 계열이 함께 열리는 경우가 많아요.
2. [huggingface.co/settings/tokens](https://huggingface.co/settings/tokens) 에서 **Read** 권한 토큰을 만드세요.
3. `pc\models_download.ps1` 을 실행하면 승인이 필요한 모델의 페이지 주소를 보여 주고, 브라우저로 열지 물어봐요. Enter 를 누르면 페이지가 모두 열려요. 동의한 뒤 토큰을 붙여 넣으면 돼요. 토큰은 화면과 기록 파일에 남지 않아요.

엑셀의 모델 목록 시트에서도 모델 이름을 누르면 Hugging Face 페이지가 열려요.

토큰 없이 Enter 를 누르면 승인이 필요한 모델만 건너뛰고 나머지를 받아요.

## 스크립트가 하는 일

### 접근 PC: pc\models_download.ps1

1. **점검**: uv가 있는지, Hugging Face와 파일 서버에 접속되는지, 남은 공간이 충분한지 확인해요.
2. **내려받기**: 파일마다 이어받기로 받아요. 받은 양이 늘고 있는 동안은 몇 번을 끊겨도 계속 이어받고, 받은 양이 전혀 늘지 않은 채 연속 30번(약 2시간) 끊길 때만 그 모델을 포기해요.
3. **검사**: 받은 파일마다 크기와 sha256 을 Hugging Face가 알려 준 값과 비교해요. 다르면 지우고 다시 받아요.
4. **올릴 준비**: B200 서버에서 확인할 체크섬 목록(`MANIFEST.sha256`)과 B200 서버 스크립트를 `models` 폴더에 넣어요.

### B200 서버: server/models_install.sh

1. **점검**: 체크섬으로 올리는 중에 손상되거나 빠진 파일이 있는지, 남은 공간이 충분한지 확인해요.
2. **옮기기**: `~/shared/models/<만든 곳>/<모델>` 로 옮겨요.
3. **검사**: safetensors 파일을 열어 텐서 목록이 있는지 확인하고, 모델별 크기와 라이선스를 보여 줘요.

## B200 서버에서 불러오기

B200 서버에는 인터넷이 없으니 Hugging Face에 접속하지 않도록 설정하고, 경로로 불러오세요.

```bash
# [B200 서버] 터미널
export HF_HUB_OFFLINE=1
```

```python
from pathlib import Path
M = Path.home() / "shared/models"

# transformers
from transformers import AutoModel, AutoProcessor
model = AutoModel.from_pretrained(M / "facebook/dinov3-vitl16-pretrain-lvd1689m")

# trust_remote_code 가 필요한 모델(C-RADIO, Sa2VA): 코드 파일도 함께 받아 두었어요
model = AutoModel.from_pretrained(M / "nvidia/C-RADIOv4-H", trust_remote_code=True)

# timm: 받아 둔 가중치 파일을 직접 지정해요
import timm
model = timm.create_model(
    "vit_large_patch16_dinov3.lvd1689m", pretrained=True,
    pretrained_cfg_overlay={"file": str(M / "timm/vit_large_patch16_dinov3.lvd1689m/model.safetensors")},
)
```

GOOSE-M2F: 모델 구조가 GitHub 코드에 있어서, 함께 받은 `code` 폴더를 경로에 넣고 불러와요. 코드가 바탕 모델 `facebook/mask2former-swin-large-cityscapes-semantic` 을 읽으니 같이 받아 두었어요.

```python
import sys, torch
G = M / "XYZ9843/GOOSE-M2F"
sys.path.insert(0, str(G / "code"))
from src.model import GOOSEMask2Former   # 사용법: G/"code/instructions/instructions.md"
ckpt = torch.load(G / "best_model.pth", map_location="cpu", weights_only=False)
```

코드 안에서 `facebook/mask2former-swin-large-cityscapes-semantic` 을 이름으로 부르는 곳은 `str(M / "facebook/mask2former-swin-large-cityscapes-semantic")` 경로로 바꾸세요.

깊이 모델:

```python
# Depth Anything V2: transformers 로 바로 불러요
from transformers import pipeline
depth = pipeline("depth-estimation", model=str(M / "depth-anything/Depth-Anything-V2-Metric-Outdoor-Large-hf"), device=0)
```

Depth Anything 3(`DA3METRIC-LARGE`, `DA3MONO-LARGE`)는 `depth_anything_3` 코드가 있어야 불러올 수 있어요. 이 코드는 numpy 1.x를 요구해서 공용 환경에 넣지 않았어요. 쓰려면 담당자에게 따로 반입을 요청하세요.
`DA3METRIC-LARGE` 의 출력은 기준 초점 거리 300 픽셀로 맞춘 값이에요. 미터로 바꾸려면 `출력 × 초점 거리(픽셀) / 300` 을 하세요.

segmentation-models-pytorch 의 인코더 가중치(`enc` 그룹)는 smp가 Hugging Face 캐시에서 찾아요. 캐시 위치를 공용 폴더로 바꾸는 방법은 B200 서버에서 써 본 뒤 이 문서에 더할게요.
