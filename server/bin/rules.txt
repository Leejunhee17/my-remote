B200 서버 사용 규칙  (자세한 설명: 엑셀·마크다운 '서버 사용 규칙')

 1. 접속하면 이름을 입력한다
    자동으로 물어봐요. 이름이 있어야 누가 GPU를 쓰는지 보여요.
    → 안 지키면: '누군지 모름'(빨강)으로 표시되고, 관리자가 종료할 수 있어요.

 2. GPU는 b200 으로 실행한다
    b200 run auto python train.py     (빈 GPU를 골라 주고, 접속이 끊겨도 계속 돌아요)
    → 남이 쓰는 GPU는 b200 이 막아 줘요. 직접 실행하다 겹치면 늦게 시작한 쪽을 관리자가 종료해요.

 3. 그룹 GPU는 그 그룹이 먼저, 공용 GPU는 선착순
    다른 그룹 GPU는 비어 있을 때만 빌려 쓰고, 그 그룹이 요청하면 30분 안에 비워요.
    → 30분이 지나면 관리자가 빌려 쓴 작업을 종료해요.

 4. 파일은 내 작업 폴더(/app/workspace/내이름)에 둔다
    접속하면 자동으로 이동해요. 홈(~)은 10 GB 라 두지 않아요. 끝난 결과는 NAS로 옮겨요.
    → 디스크가 80%를 넘으면 많이 쓰는 사람부터 정리를 요청해요.

 5. 공용 폴더(/app/shared)는 읽기만 한다
    공용 패키지·데이터셋·모델 추가는 관리자에게 요청해요. 개인 패키지는 내 Python 환경에.
    → 시스템이 쓰기를 막아요.

 6. 도커 이미지는 들여온 사람이 관리한다
    b200 image-load 로 들여오고, 30일 넘게 안 쓰면 b200 rmi 로 지워요.
    → 보고서에 이름이 올라가고, 2주 더 지나면 관리자가 지워요.

자주 쓰는 명령: b200(현황)  b200 run  b200 attach  b200 stop  b200 docker  b200 help
