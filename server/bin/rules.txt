B200 서버 사용 규칙  (자세한 설명: 엑셀·마크다운 '서버 사용 규칙', 사용법: 사용_안내.md)

 1. 접속하면 이름을 입력한다
    자동으로 물어봐요. 세 번 틀리면 접속이 끊겨요.
    → 이름 없이는 서버를 쓸 수 없어요.

 2. GPU는 b200 으로 받는다
    실험·디버깅 b200 shell auto,  학습 b200 run auto python train.py.  그냥 실행하면 GPU가 안 보여요.
    → 남이 쓰거나 잡아 둔 GPU는 b200 이 막아요. 누군지 모르는 GPU 작업은 60분 뒤 자동으로 멈춰요.

 3. 내 그룹 GPU와 공용 GPU를 쓴다 (한 사람 최대 4장)
    auto 는 내 그룹·공용에서만 골라요. 다른 그룹 GPU는 번호를 적어 빌리고, 그 그룹이 b200 claim 하면 돌려줘요.
    → 반납 요청 30분 뒤 빌린 작업이 자동으로 멈춰요.

 4. 남의 작업은 건드리지 않는다
    멈추는 건 내 작업만(b200 stop). 우리 그룹 GPU를 돌려받을 때는 b200 claim.
    → 같은 계정이라 시스템이 막지 못해요. 관리자가 HIWARE 접속 기록으로 확인해요.

 5. 파일은 내 작업 폴더(/app/workspace/내이름)에 둔다
    홈(~)은 모두가 같이 쓰는 10 GB 라 파일을 두지 않고, ~/.bashrc 는 고치지 않아요.
    공용 폴더(/app/shared)는 읽기만 돼요. 공용 패키지·데이터셋·모델 추가는 관리자에게 요청해요.
    → 디스크가 80%를 넘으면 많이 쓰는 사람부터 정리를 요청해요.

 6. 도커 이미지는 들여온 사람이 관리한다
    b200 image-load 로 들여오고, 안 쓰면 b200 rmi 로 지워요.
    → 마지막 사용 후 30일이면 알림, 45일이면 관리자가 지워요.

자주 쓰는 명령: b200(현황)  b200 shell auto  b200 run auto <명령>  b200 ps  b200 attach  b200 stop  b200 help
