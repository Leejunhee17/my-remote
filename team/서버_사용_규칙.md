# B200 서버 사용 규칙

B200 서버(GPU 8장)는 팀원 모두가 계정 하나(`shareduser`)로 같이 써요. 서버 입장에서는 모두가 같은 사람이라, **접속할 때 입력한 이름**과 **`b200` 명령**으로 서로를 구분해요.
명령별 자세한 사용법, Python 환경, 모델 불러오기, 도커는 `사용_안내.md`에 있어요.

## 규칙 6가지

| | 규칙 | 이렇게 하세요 | 안 지키면 |
|---|---|---|---|
| 1 | **접속하면 이름을 입력한다** | 자동으로 물어봐요. '팀원' 시트의 이름을 입력해요. 세 번 틀리면 접속이 끊겨요 | 이름 없이는 서버를 쓸 수 없어요 |
| 2 | **GPU는 `b200`으로 받는다** | 실험·디버깅 `b200 shell auto`, 학습 `b200 run auto python train.py`. 그냥 실행하면 GPU가 안 보여요 | 남이 쓰거나 잡아 둔 GPU는 `b200`이 막아요. 누군지 모르는 GPU 작업은 60분 뒤 자동으로 멈춰요 |
| 3 | **내 그룹 GPU와 공용 GPU를 쓴다** (한 사람 최대 4장) | `auto`는 내 그룹·공용에서만 골라요. 다른 그룹 GPU는 번호를 적어 빌리고, 그 그룹이 `b200 claim`하면 돌려줘요 | 반납 요청 30분 뒤 빌린 작업이 자동으로 멈춰요 |
| 4 | **남의 작업은 건드리지 않는다** | 멈추는 건 내 작업만(`b200 stop`). 우리 그룹 GPU를 돌려받을 때는 `b200 claim` | 같은 계정이라 시스템이 막지 못해요. 관리자가 HIWARE 접속 기록으로 확인해요 |
| 5 | **파일은 내 작업 폴더에 둔다** | `/app/workspace/<이름>`. 홈(~)은 모두가 같이 쓰는 10 GB라 파일을 두지 않고 `~/.bashrc`는 고치지 않아요. 공용 폴더는 읽기만 돼요 | 디스크가 80%를 넘으면 많이 쓰는 사람부터 정리를 요청해요 |
| 6 | **도커 이미지는 들여온 사람이 관리한다** | `b200 image-load`로 들여오고, 안 쓰면 `b200 rmi`로 지워요 | 마지막 사용 후 30일이면 알림, 45일이면 관리자가 지워요 |

서버에서 `b200 rules`를 입력해도 같은 규칙이 나와요.

## 자주 쓰는 명령

| 하고 싶은 것 | 명령 |
|---|---|
| GPU 현황 보기(누가 어느 GPU를 쓰는지) | `b200` |
| GPU를 배정받아 실험·디버깅 | `b200 shell auto` (2장이면 `auto:2`) |
| 학습 시작(접속이 끊겨도 계속) | `b200 run auto python train.py` |
| 내 작업 목록 / 화면 보기 / 멈추기 | `b200 ps` / `b200 attach 번호` / `b200 stop 번호` |
| 도커로 실행 | `b200 docker auto <이미지> python train.py` |
| 도커 이미지 들여오기 | `b200 image-load` |
| 우리 그룹 GPU 돌려받기 | `b200 claim <GPU 번호>` |
| 전체 도움말 | `b200 help` |

## GPU 배분

| GPU | 그룹 |
|---|---|
| 0 | 자율주행매니저 |
| 1, 2 | 인지 |
| 3, 4 | 판단 |
| 5, 6, 7 | 공용(선착순) |

엑셀 'GPU 배분' 시트와 같아요. 서버에서 `b200`을 입력하면 배분과 지금 쓰는 사람이 같이 보여요.

## 폴더

| 위치 | 내용 | 권한 |
|---|---|---|
| `/app/workspace/<이름>` | 내 코드, 실험, 결과. 접속하면 자동으로 이동하고, `$B200_WS`로도 쓸 수 있어요 | 쓰기 |
| `/app/shared/datasets`, `models` | 공용 데이터셋, 사전학습 모델 | 읽기만 |
| `/app/shared/wheels`, `venv`, `tools` | 공용 휠, 공용 Python 환경, 기초 프로그램 | 읽기만 |
| `/app/inbox/images/<이름>` | 내가 올린 도커 이미지 파일 | 쓰기 |
| 홈 `~` | 모두가 같이 쓰는 10 GB. 파일을 두지 않아요 | 쓰기 |
