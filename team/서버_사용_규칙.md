# B200 서버 사용 규칙

B200 서버 2대는 팀원 모두가 계정 하나(`shareduser`)로 같이 써요. 서버 1은 GPU 8장, 서버 2는 다른 팀과 같이 써서 **4~7번 4장만** 우리 팀 것이에요. 서버 입장에서는 모두가 같은 사람이라, **접속할 때 고른 이름**으로 서로를 구분해요.
서버는 막기보다 **알려 줘요.** 새로 외울 명령은 없고 `docker`, `nvidia-smi`를 그대로 써요. 자세한 사용법은 `사용_안내.md`에 있어요.

## 규칙 5가지

| | 규칙 | 이렇게 하세요 | 서버가 하는 일 |
|---|---|---|---|
| 1 | **접속하면 이름을 고른다** | 접속하면 나오는 목록에서 내 번호를 입력해요 | 내 컨테이너와 GPU 옆에 이름이 붙어요. 안 고르면 '이름 없음'으로 보여요 |
| 2 | **빈 GPU를 골라 번호로 쓴다** | `nvidia-smi`로 빈 GPU를 보고 `docker run --gpus '"device=5"'`. 내 그룹·공용 먼저, 한 사람 4장까지 | 남이 쓰는 GPU를 고르면 실행 전에 경고하고 한 번 물어봐요. 겹쳐 쓰면 양쪽에 알림 |
| 3 | **다른 그룹 GPU는 빌려 쓰고, 말하면 돌려준다** | 비어 있을 때만 빌려요. 그 그룹이 말하면 `docker stop`으로 돌려줘요 | 빌릴 때 경고로 알려 줘요 |
| 4 | **다 쓰면 GPU를 놓는다** | `docker stop <컨테이너>`. 남의 컨테이너는 건드리지 않아요 | GPU를 잡고 12시간 내내 사용률 0%면 알림 |
| 5 | **파일은 내 작업 폴더에 두고, 안 쓰는 이미지는 지운다** | `/app/workspace/<내 이름>`. 홈(~)은 모두가 같이 쓰는 10 GB예요 | 디스크가 85%를 넘거나 이미지를 30일 동안 안 쓰면 알림 |

알림은 열어 둔 창에 한 줄로 뜨고, 다음에 접속할 때도 보여 줘요. 같은 알림은 하루나 한 주에 한 번만 와요.

## 자주 쓰는 명령

| 하고 싶은 것 | 명령 |
|---|---|
| GPU별 쓰는 사람 보기 | `nvidia-smi` (아래 **누가 쓰나** 표) |
| 컨테이너와 주인 보기 | `docker ps` |
| 이미지 들여오기 | `docker load -i 파일.tar` |
| 컨테이너 만들기 | `docker run -dit --name 이름 --gpus '"device=5"' --shm-size 32g -v /app/workspace/<내 이름>:/workspace -v /app/shared:/app/shared:ro 이미지 bash` |
| 컨테이너 들어가기 | `docker exec -it 이름 bash` |
| GPU 놓기 / 다시 켜기 | `docker stop 이름` / `docker start 이름` |
| 파일 올리기·내려받기 | FileZilla |

## GPU 배분

| GPU | 서버 1 (server1) | 서버 2 (server2) |
|---|---|---|
| 0 | 자율주행매니저 | **다른 팀(쓰지 않아요)** |
| 1 | 인지 | **다른 팀** |
| 2 | 인지 | **다른 팀** |
| 3 | 판단 | **다른 팀** |
| 4 | 판단 | 인지 |
| 5 | 공용(선착순) | 판단 |
| 6 | 공용 | 공용 |
| 7 | 공용 | 공용 |

엑셀 'GPU 배분' 시트와 같아요. 서버 2의 그룹 배분은 임시예요. `nvidia-smi` 아래 표에도 배분과 지금 쓰는 사람이 같이 보여요.
서버 2에서 `--gpus 2` 처럼 장 수만 쓰면 다른 팀 GPU(0번부터)를 잡아요. 꼭 번호로 정하세요.

## 폴더

| 위치 | 내용 | 권한 |
|---|---|---|
| `/app/workspace/<내 이름>` | 내 코드, 이미지 파일, 결과. 접속하면 자동으로 이동해요 | 쓰기 |
| `/app/shared/datasets`, `models` | 공용 데이터셋, 사전학습 모델 | 읽기만 |
| `/app/shared/tools` | 서버 화면에서 쓰는 기초 프로그램(tmux, nvtop, rsync 등). 접속하면 바로 써요 | 읽기만 |
| 홈 `~` | 모두가 같이 쓰는 10 GB. 파일을 두지 않아요 | 쓰기 |
| NAS `/data/shareduser/backup/<내 이름>`, `images/<내 이름>` | 오래 둘 결과·체크포인트, 도커 이미지 보관. 두 서버에서 같이 보여요 | 쓰기 |
| NAS `/data/shareduser/transfer` | 서버 사이에 옮길 파일. 옮긴 뒤 지워요 | 쓰기 |
| NAS `/data/shareduser/archive` | 관리자가 반입한 원본 | 건드리지 않기 |
